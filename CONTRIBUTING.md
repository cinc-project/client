# Contributing to Cinc Client

This repository holds the build harness for Cinc Client, the community build of Chef Infra Client. We welcome contributions through merge requests on GitLab. See
<https://www.cinc.sh/contributing/> for more about contributing to the Cinc
Project.

Please sign off every commit under the
[Developer Certificate of Origin](https://developercertificate.org/) by
committing with `git commit -s`.

## Merge policy

This is the interim rule until the project publishes its governance model.

- Open a merge request for every change. Do not push straight to the default
  branch or to a release branch.
- Only Maintainers can merge into the default branch and the protected release
  branches.
- A Maintainer reviews the merge request first. The person who merges is not
  its author.
- The pipeline must pass before merge.
- We aim for two reviews on these products and will require them once GitLab
  approval rules are available to the project.
- In an emergency, such as a broken release or a security fix, a Maintainer
  may merge without review, including their own merge request. Say why on the
  merge request when you merge, and ask for a review afterwards.
